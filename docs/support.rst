Questions and feedback
======================

For questions about using GaiaXPy, bug reports or feature requests, please use the
`GitHub issue tracker <https://github.com/gaia-dpci/GaiaXPy/issues>`_.

Check the :doc:`faqs`, :doc:`caveats` and existing issues first. If your question
is not covered, open a new issue and describe what you are trying to do.

When reporting a problem, include your GaiaXPy and Python versions, the function
call, the complete error message and a small example that reproduces it.
